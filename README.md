# InsightGen Bio

Create a Persian RTL bioinformatics research platform with an interactive conditional research wizard, researcher accounts, project dashboards, consultation booking, project file management, scientific tooltips, and an admin dashboard.

Create a premium interactive biotechnology and bioinformatics research platform website.

The website is a private Bioinformatics Core Facility serving university professors, principal investigators, graduate students, research laboratories, and life science researchers.

The platform helps researchers move from a research question to a complete bioinformatics strategy, data analysis, biological interpretation, and publication-ready results.

The website should feel like a modern biotech SaaS platform combined with an academic research core facility.

Do NOT create a generic consulting website or a thesis-writing service.

Brand positioning:

"From Research Question to Biological Insight"

Main services:

- Bioinformatics Consultation

- Research Design Support

- Bulk RNA-seq Analysis

- Single-cell RNA-seq Analysis

- Public Dataset Analysis (GEO, SRA, TCGA)

- Functional and Pathway Analysis

- Network Biology

- Biomarker Discovery

- Microbiome Analysis

- Genomics Analysis

- Custom Bioinformatics Projects

- Scientific Visualization

Target users:

- University researchers

- Professors and PIs

- PhD students

- Biomedical laboratories

- Biotechnology researchers

## Main Interactive Feature

Create a highly visible interactive Research Project Builder.

Do not use a blank contact form.

The website should guide users through a step-by-step scientific questionnaire.

The wizard should ask:

1. Research stage:

- I have a research idea

- I have experimental data

- I need bioinformatics analysis

- I want to analyze public datasets

2. Research field:

- Cancer

- Neuroscience

- Immunology

- Pharmacology

- Microbiology

- Genetics

- Other

3. Organism:

- Human

- Mouse

- Rat

- Cell line

- Organoid

- Plant

- Microorganism

4. Data type:

- Bulk RNA-seq

- Single-cell RNA-seq

- WES/WGS

- Microbiome

- Public dataset

- Not sure

5. Research goal:

- Find differentially expressed genes

- Discover biological pathways

- Identify biomarkers

- Find therapeutic targets

- Identify cell populations

- Validate findings

- Generate publication figures

After completion, generate a Project Summary page.

Example:

Research area:

Neuroscience

Organism:

Mouse

Data:

RNA-seq

Goal:

Biomarker discovery

Recommended next step:

Bioinformatics expert consultation
